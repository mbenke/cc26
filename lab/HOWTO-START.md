1. Start a `uv` project by running the following command next do the `support` directory (downloaded from https://github.com/mbenke/cc26/tree/main):
```
uv init --no-package lqua
```
(the name of the project does not gave to be `lqua` of course).

2. Change directory to `lqua` and:

3. Set/verify `.python_version`.

4. Adjust `pyproject.toml`:
```
dependencies = [
    "mrj-support",
]

[tool.uv.sources]
mrj-support = { path = "../support", editable = true }
```

5. Run `uv sync`, it may be necessary to add the `README.md` file to the `support` directory.

6. Create a compiler schema and clean up the no longer needed `main.py` file:
```
cat ../support/compiler_skel.py main.py > compile.py
rm main.py
```

7. Create a project with git repo on gitlab.mimuw.edu.pl, gitlab.uw.edu.pl or github.

8. Connect your local project to the remote git repo:

- either brutally: remove `.git` directory created by `uv`, run `git clone`, add files created by `uv init`.

- or in a more subtle way using commands like:
```
# 1. Stage and commit the files generated by uv
git add .
git commit -m "Initial commit from uv"

# 2. Link your local repository to the remote one (replace with your actual URL)
git remote add origin https://gitlab.mimuw.edu.pl/cośtam/cośtam.git

# 3. Rename the branch to main (if not already main) and push
git branch -M main
git push -u origin main
```

9. Complete gradually the compiler, without forgetting to commit and push from time to time, and test using
```
uv run compile.py <input.lqua>
```
